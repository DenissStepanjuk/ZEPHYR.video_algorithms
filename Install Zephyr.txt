https://docs.zephyrproject.org/latest/develop/getting_started/index.html


Подключение libmpix:

1) Создайте submanifest:
cd ~/zephyrproject

mkdir -p zephyr/submanifests

nano zephyr/submanifests/libmpix.yaml

2) Вставьте:
manifest:
  projects:
    - name: libmpix
      url: https://github.com/libmpix/libmpix.git
      revision: main
      path: modules/lib/libmpix

3) Сохраните:
Ctrl+O → Enter → Ctrl+X

4) Скачайте libmpix:
cd ~/zephyrproject

west update

5) West должен клонировать репозиторий сюда: ~/zephyrproject/modules/lib/libmpix



Подключение TensorFlow Lite Micro:

1) Перейдите в корень workspace:
cd ~/zephyrproject

west config manifest.path
ожидается: zephyr

2) Задайте правила активации проектов манифеста:
west config manifest.project-filter -- +tflite-micro

3) Скачайте модуль tflite-micro:
west update tflite-micro

4) Убедитесь, что модуль установлен:
west list | grep tflite-micro

5) West должен клонировать репозиторий сюда: ~/zephyrproject/optional/modules/lib/tflite-micro

Anaconda Prompt:
https://anaconda.org/

1) Перейти в корневую папку:
cd C:\Users\Deniss\Desktop\ESP32-CAM\015_ESP32-CAM_Classification

2) Создать виртуальную среду: 
conda create --name ml_env python=3.8

3) Войти в виртуальную среду: 
conda activate ml_env

4) Установка (CPU):
conda install tensorflow keras jupyter pandas matplotlib seaborn scikit-learn

conda install -c conda-forge vim

5) Открыть тетрадь:
jupyter notebook


6) Удалить виртуальную среду: 
conda remove -n ENV_NAME --all


7) Конвертировать модель:
